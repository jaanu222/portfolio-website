# My Portfolio Website

This is my personal portfolio website hosted on **AWS CloudFront**.

## Live Website
[Click here to view](https://d2h6euuarr824b.cloudfront.net)

## Features
- Fully responsive static website
- Hosted on AWS S3 + CloudFront
- Uses HTML, CSS, and JavaScript

## Deployment
1. Website files uploaded to S3 bucket
2. CloudFront distribution created for global access
3. Default root object set to index.html
